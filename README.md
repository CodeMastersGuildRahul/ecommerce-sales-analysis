# 🛒 E-Commerce Sales Analysis

An end-to-end **E-Commerce Sales Data Analysis** project using **SQL, Python, and Power BI** to analyze sales performance, customer behavior, product trends, revenue, and profitability.

## 📌 Project Overview

The objective of this project is to transform raw e-commerce data into meaningful business insights that can help organizations understand sales performance and make data-driven decisions.

The project covers the complete analytics workflow:

**Raw Data → Data Cleaning → SQL Analysis → Exploratory Data Analysis → KPI Analysis → Power BI Dashboard → Business Insights**

## 🎯 Business Objectives

* Analyze overall sales and revenue performance
* Identify top-performing products and categories
* Understand customer purchasing behavior
* Analyze monthly and yearly sales trends
* Identify profitable and underperforming products
* Track important business KPIs
* Provide actionable insights through an interactive dashboard
